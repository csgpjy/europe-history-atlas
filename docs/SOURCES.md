# 资料与教材依据

本项目的文字内容以用户提供的 **吴于廑、齐世荣主编《世界史·近代史编》上卷、下卷（高等教育出版社，第 2 版）** 为主要依据；教材没有展开的条约细节、比较性判断，再用 Britannica、中文维基百科等延伸阅读补充。

> 说明：电子书的扫描页序与纸质版页码可能不一致，因此面板只标注**章节**，不强行编造页码。需要核对原文时，按下列章节查找。

## 外部补充

- **Britannica / 中文维基百科**：用于核对条约条款、战役日期与人物事件；战争页的“教材与延伸”会分别列出。
- **historical-basemaps（GPL-3.0）**：历史政权边界的示意性重建；边界不是教材插图，也不等同于精确历史勘界。
- **Natural Earth（公有领域）**：现代海岸线、河流、湖泊与城市点，用于地图定位。
- **OpenHistoricalMap（CC0）与 Cliopatria（CC BY 4.0）**：研究模式中的数据评估与外部对照，当前未作为主站底图。

## 编辑规则

1. 新增事件或战争时，先标注教材章节；没有教材依据的内容必须标明“延伸补充”。
2. 不把外部来源的推断写成教材原话；面板中的“历史意义”“各国影响”是项目作者的概括。
3. 边界与城市数据不冒充教材内容；地图页脚、README 与 DATA-LICENSE 需要保留来源说明。
4. 修订时同步更新 `data/event-significance.js`、`data/war-details.js` 与 `tools/validate.js` 的校验。
