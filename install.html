装不上应用，不耽误用

主站支持 Edge 的“安装为应用”；如果 Edge 没有这个选项，或提示“无法安装此应用”， 先用 “添加到主屏幕 / 添加到手机” 创建快捷方式。 打开后仍是完整站点，地图、战争线和研究模式都能用。

添加到主屏后的名称
01

Edge Android

  1. 用 Edge 打开 csgpjy.github.io/europe-history-atlas/
  2. 点右上角菜单 …
  3. 选 “添加到手机” 或 “添加到主屏幕”

如果菜单里有“安装应用”，优先用它；没有就用上面的快捷方式。

02

Edge 桌面

  1. 点右上角 …
  2. 进入 应用
  3. 选 “将此站点安装为应用”

如果该选项变灰，打开一个普通 Edge 窗口（不要用工作/学校配置文件）再试。

03

iPhone / iPad

  1. 用 Safari 打开同一网址
  2. 点底部分享按钮
  3. 选 “添加到主屏幕”

iOS 的 Edge 不能安装 Web App；浏览可继续用 Edge，安装请用 Safari。

为什么提示“无法安装此应用”？

  • 从 ZIP 或本地文件打开：PWA 安装要求 HTTPS 在线地址；下载的 ZIP 只能离线浏览，不能安装。请使用上面的 GitHub Pages 网址。
  • 手机没有 Google Play 服务：部分 Android 设备无法生成 WebAPK，此时用 Edge 菜单里的“添加到主屏幕”即可。
  • 工作/学校 Edge 配置：组织策略可能禁用应用安装；换个人配置文件，或用“添加到主屏幕”。
  • iPhone 上的 Edge：iOS 只允许 Safari 添加到主屏幕；这是系统限制，不是站点问题。
  • 页面刚打开就安装：等 3–5 秒让 Service Worker 完成注册，再刷新重试。
